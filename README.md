# 对照实验示例项目

这个项目是最小可验证对照实验的骨架：以浇水频率作为单一变量，比较两组植物的生长结果。目标是演示如何把“控制单一变量”从口头想法落实成干净、可复现、任何人接手都能复查结果的共享知识。

## 实验设定
- 初始条件：两组植物初始高度都为 2.0 cm
- 变量：浇水频率
  - 对照组：每 2 天浇水一次，生长更稳定
  - 实验组：每天浇水一次，期望生长速度略高但波动略大
- 观察：连续 14 天的植物高度变化

## 当前文件
- `simulate_experiment.py`：无额外依赖的纯 Python 模拟脚本，自带固定随机种子，保证结果可复现
- `results.csv`：运行脚本后自动生成的实验数据表
- `README.md`：项目说明

## 运行方式
在项目目录下执行：

```bash
python3 simulate_experiment.py
```

默认使用固定种子 42，任何人在同一脚本下都会得到完全相同的结果。

也可以自定义参数：

```bash
python3 simulate_experiment.py --days 30 --output my_results.csv --seed 123
```

## 默认运行结果
固定种子 42 下跑 14 天的最终结果示例：
- 对照组（每 2 天浇水）：约 12.57 cm
- 实验组（每天浇水）：约 14.96 cm

## 原则
这个小项目故意保持轻量，不引入不必要依赖、不写脆弱的隐形逻辑，目的是把“可验证”放在最前面。以后要扩展统计检验、绘图、多变量对比或接入真实采集数据，都可以在这个干净的基础上继续加，不用推倒重来。
